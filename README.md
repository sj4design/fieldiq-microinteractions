# Link FieldIQ — Microinteractions

Presentación estática, protegida por contraseña.

El contenido está cifrado con **AES-256-GCM**; la clave se deriva de la
contraseña con **PBKDF2-SHA256 (300.000 iteraciones)**. Este repositorio
contiene únicamente el texto cifrado (`payload.bin`) y el shell que lo
descifra en el navegador (`index.html`) — no hay fuente ni imágenes en claro.

Sin la contraseña no hay nada legible acá.
